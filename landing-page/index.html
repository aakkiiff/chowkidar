Why Chowkidar

Operational simplicity. By design.

You shouldn't need a Kubernetes cluster and a 200-page Grafana book to know when CPU is on fire.

One binary, one file

Single Go binary per role, SQLite for storage. No Prometheus, no Grafana, no Loki, no Alertmanager — and nothing to operate on top.

Five-minute setup

Clone, run docker compose up, set an admin password, register an agent. You're collecting metrics before your coffee is cold.

Opinionated UI

No PromQL. No dashboard authoring. Charts, alerts, log search — all out of the box, all tuned for "what's wrong right now?"

Features

Everything you need. Nothing you don't.

Built for the <50-host deployment. Optimized for clarity over flexibility.

System metrics

CPU, memory, disk per host. 10-second resolution. 7-day history.

Container metrics

Per-container CPU, RAM, network, restart count via Docker Engine API.

Live log streaming

Sub-second container log tail via Server-Sent Events. Searchable, filterable.

HTTP endpoint probes

Uptime gantt, p99 latency, incident history. Built-in, no extra tooling.

Threshold alerts

Sustain-window evaluation. Discord webhooks. Persistent notification log.

Projects + RBAC

Group agents by project. Per-developer agent access. Admin separation.

Security baked in

bcrypt passwords, httpOnly JWT cookies, rate limiting, SameSite=Strict.

Failure-isolated agents

Server down? Agent stays healthy. Drops samples, never the host.

Comparison

Choose your scale.

Chowkidar isn't trying to replace Prometheus at 1000 hosts. It's the right tool when you have 5–50.

Dimension Chowkidar Prometheus stack
Components to operate 3 (server, agent, frontend) 5+ (Prom, Grafana, Loki, Alertmanager, exporters)
Setup time 5 minutes Days of YAML
Server idle memory ~60 MB 2–4 GB
Disk footprint per agent / day ~50 MB Hundreds of MB
Query language None — opinionated UI PromQL
Backups Copy a SQLite file TSDB snapshot + restore
Federation, 100+ hosts Not the goal Native
Ecosystem (exporters, integrations) Limited Vast
Quick start

Five minutes. Three steps.

All you need is Docker and a host you want to monitor (can be the same machine).

1

Run the stack

Clone the repo and bring up the server + dashboard with Docker Compose.

git clone .../chowkidar.git cd chowkidar docker compose up -d
2

Create admin + project

Open the dashboard at localhost:9999, set an admin password, create a project, register an agent. Copy the token.

# dashboard guides you through it open http://localhost:9999
3

Run the agent

Drop the token into .env, build the agent, and run. It appears on the dashboard within 15 seconds.

cd agent echo "AGENT_TOKEN=..." > .env go run .

Try it on a single host today.
